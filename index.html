[ 11 ]市场与竞品

周边产品

SPOTIFY WRAPPED / 网易云年度平台年度回顾

数据丰富、社交传播强、视觉识别成熟。但由平台主导，无法持续输出内容。

艺人周边表达我喜欢谁

消费场景成熟、供应链完善。但围绕单个艺人或专辑，个性化程度低，无法体现用户自己的音乐结构。

数据可视化工具工具化的可视化

能展示复杂关系，方法论成熟。但偏功能化，缺少身份表达，几乎没有实体应用路径。

CLOUDIFY表达我的音乐结构

数据驱动 / 可生成 / 可穿戴，三者合一。代价是依赖平台数据授权，实体成本高于纯数字产品。

SSTRENGTHS 优势

  • 数据来自用户自身，个人化程度天然最高
  • 每个人的生成结果不同，无法被简单复制
  • 音乐与身份表达之间有天然联系
  • 同时可作为数字作品与实体产品

WWEAKNESSES 劣势

  • 需要用户授权音乐平台数据
  • 设计不当极易退化成无辨识度的图案 dashboard
  • 复杂数据转成服装图形时存在信息损失
  • 小批量打样单件成本高，难以摊薄

OOPPORTUNITIES 机会

  • 个性化消费与小批量定制持续增长
  • 音乐与时尚的联系正在被重新激活
  • 年轻用户已习惯主动分享听歌数据
  • Data Art 正成为新的视觉内容类别

TTHREATS 威胁

  • 音乐平台 API 权限或政策发生变化
  • 用户对个人数据授权存在顾虑
  • 视觉过于复杂会降低穿着意愿
  • 平台自身可能推出官方数据周边

第一阶段验证目标：
个人音乐数据服装图案是否受欢迎？

R1
数据获取风险平台数据权限或 API 政策发生变化
应对把数据获取与视觉生成彻底分离：API → 标准化数据集 → 可视化。即使无法实时连接，视觉系统仍可基于已获得的匿名数据集独立运行。
R2
数据过于复杂50 首歌同时进入系统，画面变成一团噪点
应对建立三级信息层级：主数据 → 次级指标 → 装饰数据，并严格控制同时使用的视觉变量不超过五个。
R3
可读性下降过度追求视觉效果，用户看不懂自己的数据
应对同时保留数据图与视觉图。抽象图形负责表达身份，原始表格负责建立信任。
R4
衣服过于复杂网页上成立的构图，印到身上并不成立
应对建立两套版本。虚拟版本允许复杂信息；可穿戴版本只保留最有辨识度的部分，并为身体运动、缝线位置与印刷工艺重新排布。
R5
最终视觉缺乏个性所有用户套用同一模板，退化成普通周边
应对让数据真正参与生成。不同的数据必须导致不同的形状、密度、构图与比例——页面上的「换一位用户」按钮就是对这一点的持续验证。
